# HaShqipTiPlako

## Inspired by CS50x and the wordle problem.
### A simple game that implement the wordle idea by a beginner in Android app development.
#### Game ask user for how many words should the word contain.  After that random word is generated and masked word.length(#).  
#### User than has word.length + 1 tries to guess the word. Input that has length > or < word is disgarded, also if it contais spaces or punctuation symbols.
#### When user guesses the correct position of the letter # is replaced with the letter he found.
#### When user guesses a word that contain the one of the letters but not in the correct position app displays that letter followed by a ?.
#### When user guesses the secret word than congratulation is displayed on the screen and two buttons one that gives the user the choice to play with current settings or reset word length.
#### When user fails to guess the word almost there is displayed on the screen and two buttons one that gives the user the choice retry or reset word length.
